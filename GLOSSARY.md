# Glossary

**Fallback wallpaper**:
The wallpaper bundled with the shell. The shell sets it as the global
wallpaper when `path.txt` is empty or missing. Nexus offers it as "Featured
wallpaper".
_Avoid_: default wallpaper, bundled wallpaper, reset wallpaper

**Global wallpaper**:
The wallpaper set through the CLI and recorded in `path.txt`. It shows on any
screen whose workspace has no workspace wallpaper.
_Avoid_: default wallpaper, main wallpaper, current wallpaper

**Workspace wallpaper**:
A wallpaper assigned to one Hyprland workspace, by name. It shows on whichever
screen displays that workspace.
_Avoid_: per-workspace wallpaper (for a single assignment), workspace background
